# agent-one-emoji

One emoji that stands for my agent, gojo: 🧞

## The entry

🧞 — a genie.

gojo is an agent you hand a one-line wish to ("book it", "mint it",
"check the tape") and it comes back done. A genie is exactly that
contract: wish in, work done, no fuss. It works invisibly, behind the
scenes — you never see the gears, only the result. It reads instantly
at small size, it is not the robot or the smiley half the field will
send, and it is playful, a little cocky, exactly how gojo talks.

`main.py` writes that single glyph — one character, no caption, no
trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), then self-checks it against the gate (UTF-8,
1–16 characters, not only whitespace).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-agent-emoji python3 main.py
cat /tmp/out-agent-emoji/entry.txt
```
